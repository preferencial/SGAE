menu_book Guia Rápido de Uso

Para usar o Design System em qualquer arquivo HTML do seu projeto Google Apps Script:

<!DOCTYPE html> <html> <head> <!-- Incluir o Design System --> <?!= include('DesignSystem'); ?> </head> <body> <!-- Usar as classes --> <button class="btn btn-primary">Meu Botão</button> </body> </html>
lightbulb Dica: Adicione a função include() no seu arquivo Code.gs para que o sistema funcione corretamente.
